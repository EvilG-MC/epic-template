### 🚀 Installation 

> Pre-requisites
- [NodeJS] v20.12.x

**1**. Clone the repo: 
```bash
git clone https://github.com/EvilG-MC/epic-template.git
```
<bt></br>
**2**. Install dependencies (I recommend: [pnpm](https://pnpm.io/installation)): 
```bash
npm install
```
<bt></br>
**3**. Compile the bot: 
* Because it is a typescript bot running in javascript.
```bash
npm run compile 

#or you can run it directly using typescript!
npm run dev
```
<bt></br>
**4**. Start the bot: 
* If everything is ok, it should run haha.
```bash
npm run start
```
<bt></br>
